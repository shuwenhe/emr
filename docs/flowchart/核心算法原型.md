# 核心算法原型（第四步）

## 1. 预处理与质量控制（QC）
- 时序分段：升温期/稳态/冷却期划分
- 时序配准：空间与时间对齐
- 辐射-温度校正：发射率与环境补偿
- 异常帧剔除：噪声、丢帧、漂移

## 2. 前向热传导模型
- 组织热传导方程建立
- 参数设定：热导率、血流灌注、代谢热
- 离散化方法：有限差分/有限元

## 3. 反问题与正则化
- 目标函数定义：表面温度变化拟合
- 约束：平滑/稀疏/生理可行性/解剖区域
- 正则化参数选择：L2/L1/TV

## 4. 迭代求解与收敛
- 优化方法：梯度下降/变分/共轭梯度
- 收敛判据：误差阈值/迭代次数/残差下降

## 5. 输出与评估
- 层析热图：深层热源分布
- 置信度估计
- 基准数据验证：仿真/体模/历史数据

## 6. 原型验收指标
- 重建误差
- 收敛速度
- 对噪声鲁棒性

## 7. 交付物
- 原型算法文档
- 可运行示例代码
- 验证报告
