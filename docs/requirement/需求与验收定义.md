# 需求与验收定义（第一步）

## 1. 业务目标
- 目标场景：患者热成像问诊 → 云端分析 → 报告生成 → 灸疗推荐 → 疗效评估
- 目标用户：患者、艾灸师、运营/管理人员
- 成功标准：报告可解释、疗法安全可控、疗效评估可对比

## 2. 角色与权限
- 患者端：上传/查看报告、查看建议
- 医疗端：审核/调整方案、查看评估
- 运营端：设备管理、数据监控、审计

## 3. 输入/输出规范（草案）
### 输入
- 红外热成像：时序温度场、采集参数、环境参数
- 基本信息：性别/年龄/部位/症状

### 输出
- 报告：结构化字段 + 可视化图像（实时热像/异常热图/层析热图）
- 方案：灸疗参数（部位、时长、强度、频次）
- 评估：前后对比指标 + 风险分级

## 4. 核心验收指标
- 准确性：异常区域识别准确率
- 稳定性：相同输入结果一致性
- 性能：报告生成时间、并发处理能力
- 安全性：推荐方案不超过阈值

## 5. 边界与约束
- 设备型号与采样频率范围
- 环境温度/湿度范围
- 数据缺失与异常处理规则

## 6. 关键用例（验收用例）
- 标准患者流程：采集 → 报告 → 推荐 → 评估
- 异常输入：缺失参数、噪声过大、时间序列断裂
- 设备异常：采集失败、标定失效

## 7. 交付物
- 需求说明（本文件）
- 验收指标清单
- 用例清单
