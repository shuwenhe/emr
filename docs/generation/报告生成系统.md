# 报告生成系统（第六步）

## 1. 报告结构
- 基本信息（脱敏）
- 指标摘要（统计、对称性、面积）
- 异常区域标注
- 层析热图与解释
- 风险分级与建议

## 2. 图像与可视化
- 实时热像
- 代谢异常热图
- 层析热图
- 参考热图

## 3. 模板与版本
- 报告模板管理
- 模板版本固化
- 多版本兼容

## 4. 输出格式
- PDF
- Web报告

## 5. 生成流程
- 数据聚合 → 指标计算 → 图像拼装 → 文本生成 → 模板渲染

## 6. 验收指标
- 报告字段完整性
- 输出一致性
- 生成耗时

## 7. 交付物
- 报告模板
- 报告生成服务
- 示例报告
