## 🔄 2. AI生成的详细流程

```
┌──────────────────────────────────────────────────────────────┐
│                   analyze_record()                           │
│                   开始处理一条记录                           │
└─────────────────┬────────────────────────────────────────────┘
                  │
                  ├─ 第1步：读取并计算基础数据
                  │   ├─ 读取CSV温度数据
                  │   ├─ 计算 min, max, avg温度
                  │   ├─ 确定 risk_level（low/medium/high）
                  │   └─ 9格区域对比分析
                  │
                  ├─ 第2步：⭐构建LLM上下文
                  │   │
                  │   └─ _build_llm_context() 函数
                  │       ├─ 患者信息（姓名、年龄、部位）
                  │       ├─ 风险等级
                  │       ├─ 温度指标汇总
                  │       └─ 异常区域列表
                  │
                  ├─ 第3步：⭐⭐⭐ AI生成诊断
                  │   │
                  │   ├─ OLLAMA_ENABLED? ─┬─ 是 → 调用AI
                  │   │                    └─ 否 → 跳过
                  │   │
                  │   └─ _generate_llm_diagnosis_and_opinion(context)
                  │       │
                  │       ├─ 第一轮生成
                  │       │   ├─ 构建prompt: "请返回JSON..."
                  │       │   ├─ 调用_ollama_generate()
                  │       │   │   └─ POST to Ollama服务
                  │       │   ├─ 提取JSON块
                  │       │   └─ 检查字数（≥80字）
                  │       │
                  │       ├─ 字数不足？
                  │       │   ├─ 是 → 第二轮重新生成
                  │       │   │        (要求≥120字)
                  │       │   └─ 否 → 直接返回
                  │       │
                  │       └─ 返回结果
                  │           {
                  │             "diagnosis": "...",
                  │             "doctor_opinion": "...",
                  │             "report_note": "..."
                  │           }
                  │
                  ├─ 第4步：规则引擎生成方案（非AI）
                  │   └─ _build_treatment_plan()
                  │       ├─ 强度等级（根据risk_level）
                  │       ├─ 疗程次数
                  │       ├─ 频率
                  │       ├─ 目标区域和参数
                  │       └─ 穴位选择（基于诊断）
                  │
                  ├─ 第5步：⭐ AI生成方案说明
                  │   │
                  │   ├─ OLLAMA_ENABLED? ─┬─ 是 → 调用AI
                  │   │                    └─ 否 → 跳过
                  │   │
                  │   └─ _generate_llm_plan_text(context, plan)
                  │       ├─ 构建plan摘要JSON
                  │       ├─ 调用_ollama_generate()
                  │       │   └─ "以下为治疗方案，请生成说明..."
                  │       └─ 返回文字说明
                  │
                  └─ 第6步：汇总数据
                      ├─ 保存AI内容到report["ai"]
                      ├─ 保存治疗方案说明
                      └─ 写入JSON文件
                         data/{record_id}/report.json
```

## 🌊 3. _ollama_generate() 的网络流程

```
┌──────────────────────────────────────┐
│  _ollama_generate(prompt)            │
│  (在llm_report.py或analysis.py)     │
└────────┬─────────────────────────────┘
         │
         ├─ OLLAMA_ENABLED check
         │   └─ False? 返回 ""
         │
         ├─ 构建HTTP请求体
         │   {
         │     "model": "qwen3:1.7b",
         │     "prompt": "你是医疗热成像...",
         │     "stream": false,
         │     "options": {
         │       "temperature": 0.2,
         │       "num_predict": 512
         │     }
         │   }
         │
         └─ 发送HTTP POST请求
            │
            ↓ POST /api/generate
         ┌────────────────────────────────┐
         │  Ollama服务 (localhost:11434)  │
         │  └─ 运行qwen3:1.7b模型        │
         └────────┬───────────────────────┘
                  │
                  ├─ 模型计算...（可能需要10-30秒）
                  │
                  └─ 返回HTTP 200
                     {
                       "response": "患者全身热成像..."
                     }
         ↑
         │ 接收响应
         │
         ├─ 解析JSON
         ├─ 提取 response 字段
         ├─ strip() 清理
         └─ 返回文本字符串

异常处理：
  ├─ URLError (网络连接失败)
  │   └─ 记录日志，返回 ""
  ├─ HTTPError (HTTP错误)
  │   └─ 记录日志，返回 ""
  ├─ TimeoutError (20秒超时)
  │   └─ 记录日志，返回 ""
  └─ JSONDecodeError (响应格式错误)
      └─ 记录日志，返回 ""
```

## 🎯 4. 决策树：AI内容如何被使用

```
report.json 已存在?
│
├─ 是 → report["ai"] 存在?
│      │
│      ├─ 是 → 【直接使用】
│      │        AI内容已生成，
│      │        在analysis.py中
│      │
│      └─ 否 → 【查询数据库或EMR】
│             尝试从其他来源获取
│             或使用默认值
│
└─ 否 → generate_docx_report() 被调用
       │
       ├─ OLLAMA_ENABLED?
       │  │
       │  ├─ 是 → 【实时生成】
       │  │        调用generate_report_ai()
       │  │        生成AI内容（备用）
       │  │
       │  └─ 否 → 【不生成】
       │          使用默认值或空值
       │
       └─ 保存DOCX
          （可能无AI章节）
```

## 📊 5. 数据转换流程

```
CSV 数据
  │
  ├─ temperature_c (浮点数)
  │   ↓
  │ 计算统计值
  │   ├─ min_c: 18.42
  │   ├─ max_c: 34.27
  │   └─ avg_c: 26.32
  │
  └─ (row, col, temp) 元组
      ↓
    网格化 (numpy array)
      ↓
    9区域分析 (3x3)
      ├─ r1_c1: 18.48 (低)
      ├─ r1_c2: null
      ├─ r1_c3: 31.45 (高)
      ├─ r2_c1: null
      ├─ r2_c2: null
      ├─ r2_c3: 34.12 (高)
      ├─ r3_c1: null
      ├─ r3_c2: 21.23 (低)
      └─ r3_c3: null
      
      ↓
    异常区域过滤 (仅high/low)
      └─ abnormal_regions: [
           {region: "r1_c1", status: "low", avg_c: 18.48, delta_c: -7.84},
           {region: "r1_c3", status: "high", avg_c: 31.45, delta_c: 5.13},
           ...
         ]

                              │
                              ↓
                    ┌─────────────────────┐
                    │ 构建LLM上下文字符串  │
                    └────────┬────────────┘
                             │
            ┌────────────────┼────────────────┐
            ↓                ↓                ↓
      患者信息字段      风险等级字段      异常区域字段
      "姓名=江小白      "low"            [{region: "r1_c1",
       性别=male                           avg_c: 18.48,
       年龄=34                             delta_c: -7.84},
       部位=全身"                          ...]

            │                │                │
            └────────────────┼────────────────┘
                             │
                             ↓
                    "你是医疗热成像评估助手...
                     患者信息：姓名=江小白...
                     风险等级：low
                     温度摘要：温度范围 18.42C - 34.27C
                     温度指标：min=18.42 max=34.27 avg=26.32
                     异常区域：[...]"
                    
                             ↓
                    ┌─────────────────────┐
                    │  发送到Ollama       │
                    │  （HTTP POST）      │
                    └────────┬────────────┘
                             │
                             ↓
                    JSON 响应（文本）
                    "患者全身热成像显示
                     温度范围在18.42℃...
                     {\"diagnosis\": \"...\",
                      \"doctor_opinion\": \"...\"}"
                    
                             ↓
                    ┌─────────────────────┐
                    │  提取JSON块         │
                    │ _extract_json_block │
                    └────────┬────────────┘
                             │
                             ↓
                    {
                      "diagnosis": "患者全身热成像...",
                      "doctor_opinion": "患者热成像...",
                      "report_note": "本报告基于..."
                    }
                    
                             ↓
                    ┌─────────────────────┐
                    │  存入report["ai"]   │
                    └────────┬────────────┘
                             │
                             ↓
                    报告JSON完成
```

## 🔁 6. 失败恢复流程

```
analyze_record() 执行中
    │
    └─ _generate_llm_diagnosis_and_opinion()
        │
        └─ _ollama_generate()
            │
            ├─ 尝试连接 localhost:11434
            │
            ├─ 网络错误? ─────────────┐
            ├─ 超时(>20s)? ──────────┤
            ├─ 响应格式错误? ────────┤
            │                        │
            │                        ↓
            │              记录ERROR日志
            │              返回 ""
            │              │
            │              ↓
            │         llm_result = {}
            │         (空dict)
            │
            └─ 成功
                返回文本
                    │
                    ↓
                _extract_json_block()
                    │
                    ├─ JSON解析失败?
                    │   └─ 返回 None
                    │       → 空dict
                    │
                    └─ JSON解析成功
                        → 返回结果

            ┌──────────────────┐
            │ 无论成功失败      │
            │ analyze_record()  │
            │ 仍然继续执行      │
            │                  │
            │ ✅ 降级为规则引擎 │
            │ ✅ 降级为默认值   │
            │ ✅ 报告仍会生成   │
            └──────────────────┘
                    │
                    ↓
            最终report.json
            (可能无"ai"字段
             或"ai"为空)
                    │
                    ↓
            generate_docx_report()
            检查 report["ai"]
                    │
                    ├─ 有内容? → 使用现成的
                    │
                    └─ 为空? → 再试一次
                        │
                        └─ 实时调用AI
                            (带try-catch)
                            │
                            ├─ 成功? → 插入DOCX
                            │
                            └─ 失败? → 跳过AI章节
                                     仍保存DOCX ✅
```
