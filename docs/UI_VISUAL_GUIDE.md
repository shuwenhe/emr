## 🎬 交互流程动画

### 操作序列1: 选择日期范围

```
时间轴:
┌─────────────────┬──────────────────┬──────────────────┬──────────────────┐
│ T0: 打开报告    │ T1: 选起始日期    │ T2: 选结束日期    │ T3: 查看结果      │
│                 │                  │                  │                  │
│ 5个报告显示     │ 4个报告显示      │ 2个报告显示      │ 2个报告显示      │
│                 │ (过滤中)         │ (过滤中)         │ (最终结果)       │
└─────────────────┴──────────────────┴──────────────────┴──────────────────┘

状态变化:
初始状态: 显示所有5个报告
         ↓
用户输入起始日期: 2026-02-10
         ↓
系统过滤: 只显示 >= 2026-02-10 的报告 (4个)
         ↓
用户输入结束日期: 2026-02-11
         ↓
系统过滤: 只显示 2026-02-10 到 2026-02-11 的报告 (2个)
         ↓
最终显示: [2026-02-11, 2026-02-10]
```

---

### 操作序列2: 重置过滤

```
时间轴:
┌──────────────────┬──────────────────┬──────────────────┐
│ T0: 已过滤状态   │ T1: 点重置       │ T2: 显示所有     │
│                  │                  │                  │
│ 2个报告显示      │ 清空日期框       │ 5个报告显示      │
│ (过滤后)         │ (清空中)         │ (重置后)         │
└──────────────────┴──────────────────┴──────────────────┘

状态变化:
已过滤: 显示2个报告 (2026-02-10 ~ 2026-02-11)
       ↓
点击重置: 日期框清空
       ↓
系统过滤: 无条件，显示所有报告
       ↓
最终显示: [2026-02-12, 2026-02-11, 2026-02-10, 2026-02-09, 2026-02-08]
```

## 📊 数据更新时序

```
用户操作                前端状态            后端请求         显示结果
─────────────────────────────────────────────────────────────────────
初始化报告列表
                        loading=true       GET /reports
                                          ↓
                                      读取报告列表
                        ↓
                        报告列表加载
                        reportFiles=[...]              显示5个报告
                        loading=false

用户选择起始日期: 2026-02-10
                        reportDateFrom=                 
                        "2026-02-10"                   立即过滤
                        重新调用                        显示4个报告
                        filterReportsForPatient()

用户选择结束日期: 2026-02-11
                        reportDateTo=
                        "2026-02-11"                   立即过滤
                        重新调用                        显示2个报告
                        filterReportsForPatient()

用户点击重置
                        reportDateFrom=""
                        reportDateTo=""                立即过滤
                        重新调用                        显示5个报告
                        filterReportsForPatient()
```
