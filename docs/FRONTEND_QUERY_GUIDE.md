# 📱 前端页面日期范围查询 - 使用指南

## 🎯 核心工作流

```
患者列表页面
    ↓
[点击患者的"报告"按钮]
    ↓
打开报告历史模态框
    ├─ 显示该患者的所有历史报告
    ├─ 显示"按日期搜索"过滤区域
    └─ 显示报告列表（日期、名称、大小）
    ↓
[选择起始日期和/或结束日期]
    ↓
列表实时过滤 ← ⚡ 无需点击搜索按钮！
    ↓
显示符合条件的报告
    ├─ [预览] - 浏览器内查看
    ├─ [打印] - 打印对话框
    └─ [下载] - 保存到本地
```

// 1. 状态管理
const [reportDateFrom, setReportDateFrom] = useState<string>('');
const [reportDateTo, setReportDateTo] = useState<string>('');

// 2. 日期过滤函数
function filterReportsForPatient(files: ReportFile[], patient: Patient | null) {
  return files.filter(file => {
    // 第一步: 按患者名称过滤
    const matchPatient = /* ... */;
    if (!matchPatient) return false;
    
    // 第二步: 按日期范围过滤
    if (reportDateFrom || reportDateTo) {
      const fileDate = new Date(file.date);
      
      // 检查是否大于等于起始日期
      if (reportDateFrom) {
        if (fileDate < new Date(reportDateFrom)) return false;
      }
      
      // 检查是否小于等于结束日期 (包括整个结束日期)
      if (reportDateTo) {
        const toDate = new Date(reportDateTo);
        toDate.setDate(toDate.getDate() + 1);
        if (fileDate >= toDate) return false;
      }
    }
    
    return true;
  });
}

}

function resetReportDateFilter() {
  setReportDateFrom('');
  setReportDateTo('');
}

## 🔧 技术细节

### 日期比较逻辑
```typescript
// ✅ 正确的日期比较方式

// 1. 字符串格式: YYYY-MM-DD
//    例: '2026-02-10' < '2026-02-11' ✓

// 2. 包含整个结束日期
//    需要将结束日期加1天后再比较
//    原因: new Date('2026-02-10') 的午夜00:00:00
//    要包含整个2月10日,需要比较 >= 2月11日午夜

const toDate = new Date(reportDateTo);
toDate.setDate(toDate.getDate() + 1);  // 加1天
if (fileDate >= toDate) return false;  // 不包含
```

### 文件日期解析
```typescript
// 文件名格式: 患者名_YYYYMMDD_HHMMSS.docx
// 例: 张三_20260210_090000.docx

const match = file.name.match(/_(\d{8})_/);
const dateStr = match[1];  // '20260210'
const date = `${dateStr.slice(0,4)}-${dateStr.slice(4,6)}-${dateStr.slice(6,8)}`;
// 结果: '2026-02-10'
```

## 🎓 常见问题

### Q1: 如何只查看某一天的报告?
**A:** 将起始日期和结束日期设置为同一天即可。

### Q2: 为什么改变日期后列表没有更新?
**A:** 列表应该立即更新。如果没有，请：
1. 检查浏览器控制台是否有错误
2. 尝试刷新页面
3. 检查日期格式是否正确 (YYYY-MM-DD)

### Q3: 能否删除已选择的日期?
**A:** 点击日期输入框右侧的×按钮，或直接清空输入框内容即可。

### Q4: 过滤后如何看到所有报告?
**A:** 点击"重置过滤"按钮清空所有日期条件。

### Q5: 支持跨月份的日期范围吗?
**A:** 完全支持。例如从2026年1月20日到2026年3月15日。
