🎯 使用步骤
第1步: 点击患者的"报告"按钮
在上方患者列表中，找到要查询的患者，点击其右侧的绿色"报告"按钮。 此时会打开一个模态框，显示该患者的所有历史报告。
第2步: 设置日期范围
在"按日期搜索"区域，您可以：
• 只选择起始日期 → 显示该日期及以后的报告
• 只选择结束日期 → 显示该日期及以前的报告
• 同时选择两个日期 → 显示该范围内的报告
注意：改变日期时，列表会实时过滤，无需点击搜索按钮
第3步: 查看过滤结果
列表会自动显示符合日期条件的报告。每个报告可以执行以下操作：
• 预览 - 在浏览器内打开预览
• 打印 - 打开浏览器打印对话框
• 下载 - 下载文件到本地
第4步: 清空过滤 (可选)
点击"重置过滤"按钮可以清空所有日期过滤条件，恢复显示该患者的所有报告。
💡 常见使用场景
📅 查看某一天的报告
起始日期 = 结束日期 = 2026-02-11
→ 只显示2月11日的报告
📊 查看近期报告
起始日期 = 2026-02-05
(不选结束日期)
→ 显示2月5日及以后的报告
📈 查看整个月份
起始日期 = 2026-02-01
结束日期 = 2026-02-29
→ 显示2月份所有报告
🔄 重置过滤
点击"重置过滤"按钮
→ 显示该患者的所有报告
