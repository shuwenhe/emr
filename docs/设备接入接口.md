# 设备接入接口

## POST /ingest
用于上传红外设备数据与采集元数据。

### 请求
- Content-Type: multipart/form-data
- 表单字段：
  - file: 红外数据文件
  - metadata: JSON 字符串

### metadata 示例
```json
{
  "device": {
    "device_id": "dev-001",
    "model": "IR-600",
    "firmware": "1.0.3"
  },
  "capture": {
    "capture_time": "2026-02-10T08:30:00Z",
    "frame_rate_hz": 15,
    "resolution": "640x480",
    "spectral_range": "8-14um",
    "distance_m": 1.2,
    "emissivity": 0.98
  },
  "environment": {
    "ambient_temp_c": 24.5,
    "humidity_percent": 45
  },
  "patient": {
    "patient_id": "P0001",
    "body_part": "shoulder"
  },
  "tags": ["baseline", "session-1"]
}
```

### 响应
- record_id: 存储记录 ID
- storage_path: 文件落盘路径
- qc_issues: QC问题列表（为空表示通过）
